# Al-Fathun Nawa: Falsafah 1-200

A study app for students of the Advanced Diploma in Al-Quranic Philosophy (Institut Falsafah Al-Quran) to understand and memorise the 200 falsafah of *Al-Fathun Nawa Jilid 7* by Philosopher D'Outreach Professor Dr. HALO-N.

Created by Afiq Rashdi, September 2026.

## Features

- **Kaji**: spaced-repetition flashcards in random order, covering every falsafah in the chosen range. Each card reveals the ayat, the Malay meaning, the surah reference, Kata Kunci Falsafah and Catitan Kaedah Pembuka Mulut.
- **Senarai**: all falsafah, searchable by number, title, meaning, surah, Kata Kunci or a romanised pronunciation of the ayat (e.g. `wahuwa ma'akum`). It also has a "Kumpulan permulaan ayat" view that groups Falsafah 101-200 by shared opening words.
- **Kuiz**: match ayat to title and title to ayat.
- **Nota**: exam notes for four pentafshilan methods (Khitab Hilalul Wasil, Syariah Khofiah, Ta'wilul Ma'ani, Al Ashlih Asbaabun Nuzul). Each has a summary card per method with expandable full explanations, prepared by Peguam Ghazali.
- **Study range**: Tahun 1 (1-100), Tahun 2 (101-200), Semua (1-200) or a custom range. It applies to Kaji and Kuiz.
- Daily goals, a countdown to the exam date, and light and dark themes.

Progress is stored in the browser (`localStorage`), so it stays on each device. There is no server or account.

## Using it

`index.html` is the whole app in one file. Open it in a browser, or host it anywhere that serves static files (e.g. GitHub Pages, Netlify). It needs an internet connection only to load Google Fonts.

## Editing

| File | What it is |
|------|------------|
| `template.html` | All HTML, CSS and JavaScript, with `__DATA_JSON__` and `__NOTES_JSON__` placeholders |
| `data.json` | The 181 falsafah entries (numbers, title, Malay meaning, surah reference, Arabic, Kata Kunci, Catitan, transliteration) |
| `notes.json` | The Nota tab content, generated by `build_notes.py` |
| `notes_source/` | The four exam-note Word documents the notes are built from |
| `build_notes.py` | Builds `notes.json`: the summary cards are defined in the script, and the full explanations are read from the Word documents |
| `logo-afiq.png` | The gold logo at the bottom of the page (transparent background), embedded by `build.py` |
| `build.py` | Combines template, data, notes and the logo into `index.html` |

After changing `template.html` or `data.json`, rebuild:

```
python build.py
```

After changing a document in `notes_source/` or the summaries in `build_notes.py`, run `python build_notes.py` first, then `python build.py`.

Never edit `index.html` directly, because the next build overwrites it.

Settings you are likely to change are near the top of the script in `template.html`:
- `DEADLINE`: the exam date used for the countdown (and the "13 Okt" label in `renderMissionBar`).
- `DAILY_KAJI_GOAL` and `DAILY_KUIZ_GOAL`: the daily targets.
- `AYAT_GROUPS`: the opening-word groups shown in Senarai.

### Arabic text and transliteration

The Arabic in `data.json` comes from the Tanzil-derived text in `tanzil_quran/` (one file per surah, one ayah per line).

- `rebuild_tanzil.py` regenerates every entry's Arabic from each entry's `surahNumber` and `ayahRange`.
- `trim_tanzil.py` then cuts entries where the book quotes only part of an ayat, using word ranges.
- `transliterate.py` generates the romanised `translit` field used by the pronunciation search.

Run all three in that order after a full Arabic rebuild, then run `build.py`. For a one-off fix, edit the entry in `data.json` directly and rebuild.

## Cloud login test (branch `cloud-login-test`)

The version with accounts and cloud sync is live at https://falsafah200.vercel.app (the old address falsafah200-test.vercel.app still works).

- Students must register or log in before using the app. Register: full name, username, email, 6-digit PIN. Log in: username + PIN.
- "Lupa PIN?" emails a reset link through Firebase.
- Progress (Kaji, daily goal, julat, theme) is saved to Firebase Firestore and merged across devices.

| File | What it is |
|------|------------|
| `cloud/cloud_ui.html` | Login screen, account sheet and Firebase sync code, added to the end of the app |
| `cloud/firebase-config.json` | Firebase web config for project `falsafah-200-test` (public by design; access is controlled by the Firestore rules) |
| `build_cloud.py` | Builds `cloud-test/index.html` from `index.html` plus the files above |
| `cloud-test/index.html` | The built test app; deploy this folder |

Build: `python build.py`, then `python build_cloud.py`.

Admin: the account registered with `afiqmonsieur@gmail.com` (after verifying the email) gets a "Papan pentadbir" button in its account sheet. It lists every student's progress and publishes the class's most-missed falsafah of the last 7 days to `stats/weekly`, which students see in the Progres tab on Fridays.

Firestore rules for the test project:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    function isAdmin() {
      return request.auth != null
        && request.auth.token.email == 'afiqmonsieur@gmail.com'
        && request.auth.token.email_verified == true;
    }
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
      allow read: if isAdmin();
    }
    match /usernames/{name} {
      allow get: if true;
      allow list, update, delete: if false;
      allow create: if request.auth != null
        && name.matches('^[a-z0-9_.]{3,20}$')
        && request.resource.data.keys().hasOnly(['uid', 'email'])
        && request.resource.data.uid == request.auth.uid
        && request.resource.data.email == request.auth.token.email;
    }
    match /stats/{doc} {
      allow read: if request.auth != null;
      allow write: if isAdmin();
    }
  }
}
```
