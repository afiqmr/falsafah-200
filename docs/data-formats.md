# Data formats

The content lives in three JSON files that `build.py` inlines into the page. Student progress
lives in the browser's localStorage and, when signed in, in Firestore.

## `data.json`: the 200 falsafah

An array of 200 objects, one per falsafah, in number order.

| Field           | Type           | Meaning                                                            |
| --------------- | -------------- | ------------------------------------------------------------------ |
| `id`            | number         | Falsafah number, 1 to 200                                          |
| `noStart/noEnd` | number         | Same as `id` (kept from the older 181-card numbering)              |
| `title`         | string         | Title in capitals, as in the book                                  |
| `text`          | string         | Maksud in Bahasa Melayu                                            |
| `surahNumber`   | number         | Surah number                                                       |
| `surahName`     | string         | Surah name as written in the book                                  |
| `ayahRange`     | string         | `"191"` or `"8-10"`                                                |
| `surahDisplay`  | string         | `Surah 3: Al Imran, Ayat 191`                                      |
| `rangeLabel`    | string         | `Falsafah 1`                                                       |
| `arabic`        | string         | Uthmani text of the part of the ayat the book quotes               |
| `kataKunci`     | string[]       | Kata Kunci Falsafah                                                |
| `catitan`       | string[]       | Catitan Kaedah Pembuka Mulut (split into points at Satu:, Dua: …)  |
| `catitanShared` | string         | `"1–3"` when several falsafah share one Catitan, else empty        |
| `translit`      | string         | Romanised ayat for pronunciation search                            |
| `bookPages`     | [start, end]   | Printed page numbers in Jilid 7 (PDF page minus 69)                |

Several falsafah share the same ayat (for example 1 to 3 and 4 to 8). The Kuiz validator treats
any overlap of surah and ayah as the same ayat.

## `quiz.json`: the Kuiz bank

Written by `python quiz_bank.py` from the `Q` table in `quiz_bank.py`. Do not edit it by hand.

```json
{ "id": 99, "q": "Question stem…", "d": [31, 65] }
```

- `id`: the falsafah whose ayat is the correct answer. Answers count towards its markah.
- `q`: the question in BM, ending with the question.
- `d`: one or two distractor falsafah. The app shows two or three options.

The validator stops the build if a distractor shares an ayat (or identical text) with the answer
or another distractor, if an id is missing, or if a stem contains the falsafah title.

## `notes.json`: the Nota tab

Generated by `build_notes.py`: the summary cards are defined in the script and the long
explanations are read from the Word files in `notes_source/`. Each topic has `id`, `short`,
`title`, `istilah`, `basis`, `lead`, `key`, `groups`, `steps`, `example`, `formula`, `notes`,
`sections`, `ref` and `classShort`. The display order and the subject-year grouping are set by
`NOTE_GROUPS` in `template.html`, not by the file order.

## Browser storage

All keys start with `falsafah200_`. Keys marked **synced** are copied to `users/{uid}` in
Firestore.

| Key                  | Synced | Holds                                                            |
| -------------------- | :----: | ---------------------------------------------------------------- |
| `srs_v1`             |   ✓    | Per falsafah: `seen`, `correct`, `box`, `due`, `log`, `lt`       |
| `daily_v1`           |   ✓    | Today: `kajiIds`, `kuizCount`, `results`, `again`, flags         |
| `history_v1`         |   ✓    | Per day: `g` (Ingat), `a` (Belum ingat), `m` (missed once)       |
| `streak_v1`          |   ✓    | `{ days: ["YYYY-MM-DD", …] }` with both targets met              |
| `range_v1`           |   ✓    | Chosen julat `{ from, to }`                                      |
| `username_v1`        |   ✓    | Display name                                                     |
| `theme_v1`           |   ✓    | `light` or `dark`                                                |
| `wbw_v1`             |        | Word by word on or off                                           |
| `wbwlang_v1`         |        | `en`, `id` (BM) or `both`                                        |
| `wbwwords_v1`        |        | Cached word-by-word tables per falsafah                          |
| `listen_v1`          |        | Dengar settings                                                  |
| `notes_topic_v1`     |        | Last Nota topic                                                  |
| `weekly_seen_v1`     |        | Saturday of the last weekly popup shown                          |
| `tour_pending`       |        | First-time tour still to show                                    |
| `last_user_v1`       |        | Last username on this device                                     |
| `ids_v2`, `order_v3` |        | One-time migration markers                                       |

`log` is a string of the last 10 answers: `K`/`k` for Kaji Ingat/Belum ingat and `Q`/`q` for a
right/wrong Kuiz answer. Markah is the sum (K +1, k −1, Q +½, q −½) and decides the gred.

## Firestore

| Path                 | Written by | Holds                                                  |
| -------------------- | ---------- | ------------------------------------------------------ |
| `users/{uid}`        | student    | `profile` and `data` (the synced keys above, as JSON)  |
| `usernames/{name}`   | student    | `{ uid, email }` so a username can sign in             |
| `stats/weekly`       | admin      | The class's most-missed falsafah of the last 7 days    |
| `stats/halon-index`  | admin      | Ids of falsafah that have a Dr. HALO-N recording       |
| `stats/halon-{id}`   | admin      | One recording as base64 MP3 (under 740 KB)             |
| `pandangan/{auto}`   | student    | An opinion: `uid`, `name`, `username`, `title`, `ids` (1 to 5 falsafah, the first is the main one), `text` (30 to 1,500 characters), `status` (`baru`, `terbit`, `simpan`), `deleted`, `createdAt`; the admin adds `publishedAt` and `reviewedAt` |

The rules are in [security.md](security.md).
