# Bacaan Dr. HALO-N

Recordings by the author of Al-Fathun Nawa, Dr. HALO-N, one file per falsafah (F149.mp3 = Falsafah 149).
Mono MP3, 96 kbps. Served to the app through the jsDelivr CDN from the `audio-v1` tag:

    https://cdn.jsdelivr.net/gh/afiqmr/falsafah-200@audio-v1/audio/halon/F149.mp3

To add recordings: put new files here, commit, and create a new tag (audio-v2, ...); then update the tag in the app.
